# Refka Furqon — Product Design Portfolio

A responsive, editorial portfolio concept for a Product / UI/UX Designer. The project is intentionally dependency-free so it can run anywhere.

## Run locally

```bash
npm run dev
```

Then open `http://localhost:4173`.

## Personalise

- Profile, experience, contact details, tools, and testimonials are sourced from Refka's published Framer portfolio.
- Edit case-study dialog content in `caseStudies` inside `script.js`.
- Adjust palette and radii in `design-system/tokens.css`.
- Project and profile images are stored locally in `assets/`.

## Included interactions

- Scroll-based content reveals
- Responsive project gallery
- Interactive case-study dialogs
- Asymmetric wide–narrow project grid
- Static project images with blurred hover overlays
- Project hover cursor and motion
- Pointer-responsive hero notes
- Reduced-motion accessibility support
- Live Jakarta time in the footer
